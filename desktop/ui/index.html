    文字组件

    直接写进键盘内存的四行文字

    这条通道不擦写固件、不需要上传图片，所以能把刷新做到两三秒一次。每屏固定四行，只接受英文、数字和常见符号；中文会显示成空格。

    显示在哪些界面

    选中的界面会被组件覆盖，没选的界面保持官方原样。

    旋钮

    两个旋钮，六个动作

    音量旋钮和屏幕旋钮都能转、也都能按。转一下和按一下各自独立配置，改完写进键盘固件，换台电脑也一样生效。

    应用全屏补丁

    请使用 USB 数据线直连，关闭官方程序。写入期间不要拔线或退出。

    备份与恢复

    不需要事先准备固件。每次应用补丁前，程序会自动读取并双重校验这把键盘的完整固件。

    恢复上次备份

    恢复最近一次应用补丁前的状态。请连接同一把键盘。

    高级选项

    跳过固件版本和旧字节检查，固定偏移可能不兼容。自动备份和写后回验仍保留。仅在确认兼容性时使用。

    诊断记录

    提交问题前请检查记录中的本机路径等个人信息。
