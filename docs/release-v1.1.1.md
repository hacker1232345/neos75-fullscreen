Windows 与 macOS 图形界面版，内置 Python/Node 与 HID/USB 原生依赖。

下载与你电脑匹配的文件：

- Windows x64：`Neos75-Windows-x64.exe`，双击运行。
- Apple 芯片 Mac（M系列，macOS 15+）：`Neos75-macOS-arm64.zip`，解压后打开 `.app`。
- Intel Mac（macOS 15+）：`Neos75-macOS-x64.zip`，解压后打开 `.app`。

没有原始备份时：USB直连键盘 → 查询屏幕 → 从设备读取备份 → 选择保存位置并确认。程序以64字节块双次读取、逐块比较，完整落盘后检查SHA256，随后尝试回到应用模式。不完整数据保留为 `.partial`，不会作为可用备份。

备份结束会自动区分：原版已匹配（可生成补丁）、已经全屏（无需重复刷写）、未知版本（仅保存，不生成/刷写）。补丁生成器严格核对代码区域SHA256及全部补丁原字节，保留每台设备的末尾4KB数据；目标再以当前备份重新生成并逐字节比对。未知代码构建不支持。

本版还包含离线自检、JPEG传输测试、固件预检/回读/刷写/恢复及日志保存。所有设备操作由用户点击；启动不连接设备，刷写/恢复需明确确认。日常GIF导入仍使用官方程序。

Windows本机已验证USB只读查询、完整备份、补丁生成与窗口运行；macOS在对应架构构建机验证打包运行时、原生模块和窗口启动，尚未连接Mac真机验证USB/DFU。Windows程序未数字签名；Mac应用为构建工具的临时签名，未做Apple Developer签名或公证。系统可能提示来源无法验证。

图片/GIF全屏补丁此前已实屏验收；本次不会为了验证窗口而重新刷写。长GIF、复杂素材、断电保留及其他固件构建仍是已记录的适配限制。

复盘和五列风险清单见 `docs/desktop-release.md`。
