# Neos75 全屏工具 v1.1.2

- 新增默认关闭的“无验证，直接打补丁”选项，“设备与补丁”和“固件维护”两页共用选择。
- 勾选后跳过固件版本哈希与补丁旧字节检查，按固定地址强制生成；预检、刷写、回验和恢复均支持此模式。命令行参数为 `--force`。
- 保留完整原始备份、禁止覆盖源文件、生成目标一致性、受限写入范围、现场扇区检查及写后逐字节回验。
- 未适配备份读取后自动选中，方便显式选择强制模式；日志和生成结果记录 force 状态。

此选项不代表新固件已获兼容性验证。已知版本默认行为保持严格校验，未知构建的强制刷写可能导致屏幕启动或显示异常；请保留本机原始备份。

提供Windows x64、Apple芯片Mac和Intel Mac。Mac要求macOS 15或更高版本；Mac真实USB/DFU与未知构建强制刷写未实机验证。Windows没有数字签名；Mac未进行Developer ID签名或Apple公证。

离线验证覆盖Python/Node强制生成一致性、未知固件默认拒绝、原始备份保留、4KB/8KB擦除模型、写入失败后的恢复、错误现场及目标拦截，以及打包程序无外部运行环境时的自检和界面启动。模拟测试不代表未知固件兼容。
