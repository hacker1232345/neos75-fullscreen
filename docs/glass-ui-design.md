# 桌面界面改造

目标：不懂固件的键盘用户也能完成全屏补丁、配置屏幕小组件。默认入口只有两个。

视觉：参考 Apple Materials 的功能层与内容层分离原则。玻璃只用于导航、按钮和浮层；正文使用安静的浅色背景。并非原生 Liquid Glass 引擎。

- 颜色：背景 #edf2f8，内容 #ffffff，正文 #172336，次要文字 #526276，强调 #0068d9，成功 #167347。
- 字体：系统 SF Pro / Segoe UI / 微软雅黑；数值使用等宽数字。
- 布局：顶部品牌与连接状态，居中胶囊导航，左侧编辑、右侧键盘预览；窄窗口自然上下排列。
- 层级：一个主要按钮；备份、恢复、诊断进入次级区域；日志不占据主界面。
- 可访问性：可见焦点、44px 点击目标、状态播报、键盘可操作排序、减少动态效果。

```text
Neos75                           USB 状态 · 刷新
                 [全屏 | 小组件]

 全屏：说明 / 一键全屏             图片与 GIF 全屏示意
 小组件：已添加 / 添加组件          480 × 360 实际渲染预览

 备份与恢复 · 诊断                         v1.3.0
```

安全验收：同一时刻一个设备任务；完整双读备份之后才允许生成与写入；未知版本默认停止；自动退出 DFU 只能发生在写后逐字节回验成功之后；恢复只使用本程序保存的同次备份与目标。UI 自动化绝不执行真实刷写。

组件验收：自由添加、删除、上下排序、预设、持久保存；自动分页避免挤压裁切；预览与实际发送同一 JPEG；未取得的数据明确不可用；默认不发送，手动开始后才占用 USB。

参考：https://developer.apple.com/design/human-interface-guidelines/materials
