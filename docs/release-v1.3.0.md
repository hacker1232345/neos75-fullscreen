# Neos75 v1.3.0：一键全屏与自由组合小组件

一个程序、两个页面。简洁的玻璃风格界面，详细日志收进诊断。

## 下载

- Windows x64：`Neos75-Windows-x64.exe`
- Apple 芯片 Mac：`Neos75-macOS-arm64.zip`
- Intel Mac：`Neos75-macOS-x64.zip`
- Linux x64：`Neos75-Linux-x64.tar.gz`（Ubuntu 22.04/24.04 及相近 glibc 桌面系统）

各平台附构建信息与 SHA256 文件。源码可用 GitHub 提供的 Source code 下载。

## 一键全屏

连接 USB，点“一键全屏”并确认，程序自动读取本机完整备份、双读校验、识别补丁链、生成目标、刷入、逐字节回验并请求退出 DFU。不需要提前准备原始备份；已是链末版本会跳过重复写入，未知固件默认停止。

补丁内容和固件兼容范围沿用 v1.2.0。Issue #1 配置仍为离线适配、待实机验收。高级“无验证，直接打补丁”默认关闭，不能把它当成未知版本自动兼容。

## 自由组合小组件

15 项组件可搜索、添加、移除、排序并自动保存，有日常、性能、网络等预设。组件较多时自动分页，预览与发送使用同一份 480×360 JPEG，避免全部压缩裁切。同步通过 USB；停止会等待当前发送结束。

温度、GPU、音量等数据取决于系统与传感器，不可用时显示 n/a。原厂协议缺少最终显示确认，发送后仍需看屏确认。无线传输尚未实现。

## Linux 首次使用

解压后运行 `./Neos75`。Qt、Python、Node、中文字体随包提供。

需要 USB 权限时，先运行一次 `sudo ./install-usb-access.sh`，重新插拔键盘，以普通用户运行程序。规则仅匹配 Neos75 的 5542:0001 与 5542:1000，不开放所有 USB 设备。不要使用 root 运行整个界面。精简系统的桌面库依赖见包内说明。

Linux 包在 Ubuntu 22.04 构建并执行无设备回归、真实界面和本机数据渲染检查；这不代表 Linux 真机 USB/DFU 已验收。Mac USB/DFU 同样保留待真机验证状态。Windows 既有固件实机证据见仓库记录。

设计参考 Apple Materials 的功能层次，由本地 WebView/CSS 实现，并非原生 Liquid Glass 引擎。
