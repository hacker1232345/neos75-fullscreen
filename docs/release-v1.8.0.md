# Neos75 全屏工具 v1.8.0

这一版做两件事：**屏幕终于能配得上机身颜色了**，以及**把小部件本身收拾干净**。

## 四套配色，对应官方四种颜色

这款键盘有 Venus 银 / Selene 灰 / Hades 黑 / Athena 白四种机身。以前屏幕上只有一套深色，
银白机身配一块黑屏，看久了很别扭。官方背景图四角其实印着 `VENUS 01` / `01 SELENE` /
`HADES 01` / `01 ATHENA` —— 配色本来就有，只是没有给自定义页用。

现在四套都用得上：

| 配色 | 机身 | 底色 | 强调色 |
| --- | --- | --- | --- |
| `hades` | Hades 黑 | 近黑深蓝 | 冷蓝 |
| `selene` | Selene 灰 | 石墨灰 | 月光银蓝 |
| `venus` | Venus 银 | 银白 | 香槟铜 |
| `athena` | Athena 白 | 象牙白 | 柔金 |

命令行直接选：

```bash
python dashboard/render.py --in state.json --out screen.jpg --theme venus
```

桌面程序在「屏幕预览」上方有一排配色圆点，点一下重画预览并记住选择。旧配置里没有这个字段时
退回 Hades 黑，不会因为少一个键就打不开。

实现上没动任何绘制逻辑，只换了颜色从哪来：13 个硬编码常量变成一张表，切换时写模块全局。
这样不需要重新 import，也不会出现「一半新色一半旧色」。

## 界面收拾了一遍

四套配色有了，界面还是那几处老毛病。这轮修的都是「看着难受」而不是「用不了」：

- **删掉右下角的 `480x360` 水印。** 那是开发时确认画布用的，用户看不懂；在银白、象牙白
  这种浅底上还像一块没擦干净的污点。
- **读不到的数不再撑满格子。** 以前取不到温度就甩一个和 CPU 同字号的大 `n/a`，看起来像屏幕
  坏了。现在缩到约一半、换成中性灰 —— 同一张卡片墨迹占比从 8.1% 降到 3.1%，而有真数据时
  是 17.9%，层次一眼能看出来。
- **日期补上星期。** `2026-11-05` → `2026-11-05 周四`。星期在绘制层算，所以采样器和桌面程序
  谁传进来都一样；串里已经有星期的就不重复添加。
- **没有电量时说明供电状态。** 台式机或电池驱动没暴露时，以前只有一个巨大的 `AC` 占满卡片，
  现在写「交流供电」或「未检测到电池」，字号小一档，把视觉重量让给真正有数的部件。
- **「运行时长」改成「已运行」并左对齐。** 三个字在窄卡里会把数值挤下去。
- 日期也跟着改左对齐：加了星期以后串变长，居中会明显偏。

这几处都配了测试，而且都做过**反向验证** —— 把旧行为临时改回去，断言必须失败。第一版测试
用「取两个点比颜色」「墨迹占比 < 12%」这种宽阈值，改回旧行为照样通过，等于没测。现在的阈值
全部按实测值取中间：水印看右下角灰度种类 ≤ 3；缺失值看墨迹占比 < 6%；电池看最高连续有字行数
< 19（小字 14 行、大数字 24 行、旧的巨 AC 31 行）。五条各自都能真的抓到回归。

## 验证

- `python -m unittest discover -s tests` → **141 项全绿**
- `npm test` → **12 组全绿**
- `--self-test`（打包版、干净路径）→ 11 项全 PASS
- `--gui-smoke` → PASS，其中三条新断言守配色：按钮数量等于注册表、当前项被标为选中、
  两套主题必须渲染出不同像素
- 四套配色各渲染一张 480×360 实图，目视比对：浅底深字可读、卡片圆角与进度条正常、
  强调色与底色区分明显

## 仍然没解决的

- **旋钮还不能在程序里改。** 固件里那张「动作号 → HID 码」的表已经解出来了
  （`0x0800375A` 的 tbb 跳转表，26 项，含静音/音量±/上下曲/播放暂停/亮度±），
  也做出了一版实验固件刷进真机（只改两个字节：音量+ 改发下一曲、音量− 改发播放暂停），
  在等实物验收。**这一步没过之前，程序里不会放出会误导人的旋钮设置界面。**
- 屏幕主控（UB32F341S）的 SWD / BOOT0 焊盘仍然没找到。UI 资源区刷坏了还能靠 DFU 重刷，
  但代码区一旦刷坏目前没有恢复通道 —— 所以刷屏幕 MCU 片这件事仍然只在自己机器上做。
- 无线模式下没有验证过。所有实测都是键盘切有线。
- 长跑只做过 40 轮，再往后的内存与句柄行为没测。
- 屏幕不能主动退出 DFU，只能等约 3 分 45 秒超时。
- Mac / Linux 上的 USB 通路没在真机上验过（CI 只跑构建与离线测试）。
