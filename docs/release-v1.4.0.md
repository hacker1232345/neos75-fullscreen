# Neos75 v1.4.0：天气、Codex 状态与组件切页

## 新增

- 天气组件：搜索并选择城市，显示当前温度、天气及数据时间。Open-Meteo 每 10 分钟刷新一次，断网显示缓存，超过一小时不再显示旧温度。未选择城市时不请求天气、不自动定位。
- Codex 组件：只读本机任务事件，显示运行、本轮完成、中断等已知状态与更新时间。留空自动跟随最近更新的任务，也可指定任务 ID。没有明确事件时显示“近期有活动”或“暂无新事件”，不推测成功、不显示虚构百分比。
- 组件页可自动轮播或固定显示当前页；固定后可用前后按钮切换其他组件页，正在发送的一帧完成后生效。
- 增加“上一界面 / 下一界面”，使用官方运行时翻页命令；为避免 USB 争用，先停止组件同步再切原厂界面。

## 六个原厂界面的限制

组件分页是电脑端生成不同画面，仍然发送到同一个自定义媒体区。官方图片流没有目标页编号；切换原厂界面，不等于获得多个独立的图片存储槽。本版没有修改或刷写新的 MCU 固件，不能让原来的图片/GIF与监控画面同时保存在两个原厂页面。

同步前界面会提示当前媒体将被替换。停止后需在官方程序重新导入原图片/GIF。原厂翻页命令已做离线协议检查，实际屏幕切换仍待真机验收，命令应答不代表画面已确认。

## 数据与环境

天气数据来自 [Open-Meteo](https://open-meteo.com/)，数据 CC BY 4.0；免费服务仅限非商业用途。当前条件由天气模型生成，并非秒级气象站观测。

Codex 本地 JSONL 读取属于尽力适配，日志格式不是稳定接口；超大/未完成记录、远程任务或旧事件无法确定当前状态。只提取状态和时间，不显示聊天正文，不读取登录凭据、不启动 Codex 或额外模型调用，也不改现有 notify/hooks。支持自有客户端将官方 app-server 状态写入本地事件桥，格式见 [组件数据源说明](widget-sources.md)。

继续提供 Windows x64、macOS arm64 / x64、Linux x64 四种包。一键补丁与固件兼容范围沿用 v1.3.0，未知固件默认拒绝。Mac/Linux USB/DFU 与本次原厂翻页都仍需真机验证。
